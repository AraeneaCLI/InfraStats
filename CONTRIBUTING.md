# Contributing to InfraStat

Thank you for your interest in contributing to **InfraStat**! We welcome all kinds of contributions including bug reports, feature requests, documentation improvements, and code enhancements.

---

## Getting Started

1. **Fork the repository**
2. **Clone your forked repository**
   ```bash
   git clone https://github.com/AraeneaCLI/infrastat.git
   ```
3. **Create a new branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Install dependencies**

   Ensure you have Python 3.8+ installed. Then, run:
   ```bash
   pip install -r requirements.txt
   ```

---

## Contribution Guidelines

### 🐞 Reporting Issues

- Use the [Issues](https://github.com/your-repo/infrastat/issues) tab to report bugs or suggest enhancements.
- Clearly describe the issue with steps to reproduce (if applicable).

### ✨ Suggesting Features

- Create a new issue with the `feature` label.
- Explain your idea and its potential benefits.

### 🛠️ Code Contributions

- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) for Python code style.
- Write clear, concise commit messages.
- Ensure code is tested and does not break existing functionality.
- Document your changes in the relevant `.md` or `.py` files if needed.

---

## Pull Request Process

1. Ensure your fork is up-to-date with the upstream repository:
   ```bash
   git fetch upstream
   git rebase upstream/main
   ```
2. Push your feature branch:
   ```bash
   git push origin feature/your-feature-name
   ```
3. Open a Pull Request (PR) and describe the changes made.
4. Wait for a maintainer to review and address any requested changes.
