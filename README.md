### Introduction  

**InfraStat** is a computer infrastructure monitoring tool designed to provide real-time insights into system performance and resource usage. Built with **Python**, it leverages an **API-based architecture** to collect, analyze, and present data on key metrics such as:

- CPU usage  
- Memory utilization  
- Disk activity  
- Network statistics  

InfraStat is built to support efficient infrastructure management and performance diagnostics for both individual systems and scalable server environments.
